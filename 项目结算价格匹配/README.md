# 项目结算价格匹配系统

本地运行的结算价格精确匹配工具。系统以台账中的“报告类别 + 计费项目”为联合键，与计费价格汇总表做精确匹配，再按人工设置的价格体系优先级选择首个非空价格。

## 运行

在当前目录执行：

```bash
uv sync
uv run python app.py
```

浏览器打开：

```text
http://127.0.0.1:8010
```

系统会自动加载当前目录中的默认台账和价格汇总表，也可以在界面中选择其他 `.xls` 或 `.xlsx` 文件。

## 规则

- 匹配键：`报告类别 + 计费项目`。
- 文本仅做 Unicode 全半角统一、首尾及空白规范化，不做模糊匹配。
- F-J 列自动识别为价格体系，顺序和启用状态可在界面调整。
- 同一匹配键在价格表中出现多次时标记为“价格表重复”，不自动取价。
- 匹配成功但所有已启用价格体系均为空时标记为“无可用价格”。
- 导出范围为当前筛选结果，结算金额在 Excel 中使用公式计算。
